# CPP Module 04

## Overview

**CPP Module 04** introduces **subtype polymorphism**, abstract classes, and interfaces through inheritance.

The exercises use classes such as `Animal`, `Dog`, `Cat`, and `WrongAnimal` to demonstrate dynamic polymorphism and virtual functions.

## Objectives

* Understand runtime polymorphism.
* Use virtual functions.
* Override methods in derived classes.
* Create abstract classes.
* Use pure virtual functions.
* Understand virtual destructors.
* Manage objects through base-class pointers.

## Skills Developed

* **C++**
* Polymorphism
* Virtual functions
* Pure virtual functions
* Abstract classes
* Inheritance
* Dynamic dispatch
* Virtual destructors
* Interfaces

## What I Learned
